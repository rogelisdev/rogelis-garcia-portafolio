# Portafolio de Desarrollo – Rogelis Garcia

Este repositorio contiene mi portafolio como desarrollador, enfocado en la construcción de soluciones prácticas mediante desarrollo backend, automatización de procesos y sistemas orientados a negocio.

El objetivo de este portafolio es presentar proyectos funcionales que demuestran habilidades técnicas, capacidad de resolución de problemas y enfoque en escenarios reales.

* Construcción de herramientas orientadas a negocio

Actualmente en proceso de fortalecimiento de habilidades en tecnologías modernas, con interés en sistemas escalables, automatización y soluciones basadas en lógica de negocio.

## Proyectos

### Sistema PQRS

Aplicación web para la gestión de peticiones, quejas, reclamos y sugerencias.

**Características principales:**

* Registro de solicitudes
* Clasificación por tipo (petición, queja, reclamo, sugerencia)
* Filtrado por estado
* Gestión dinámica de información
* Generación de reportes
* Preparado para integración con herramientas de automatización

---

### Panel de Inventario

Aplicación web para la gestión de productos, control de existencias y registro de ventas.

**Características principales:**

* Registro de productos
* Control de inventario en tiempo real
* Validación de stock en operaciones de venta
* Indicadores de bajo stock
* Historial de ventas
* Persistencia de datos mediante almacenamiento local

---

### Proyecto adicional

Espacio destinado a proyectos de mayor complejidad orientados al desarrollo backend, con énfasis en la construcción de sistemas escalables y estructurados.

**Enfoque principal:**

* Desarrollo con Java (arquitectura backend)
* Construcción y consumo de APIs REST
* Integración con bases de datos relacionales
* Implementación de lógica de negocio robusta
* Manejo de persistencia de datos
* Estructuración por capas (controlador, servicio, repositorio)

**Objetivo:**

Diseñar soluciones más cercanas a entornos empresariales, incorporando buenas prácticas de desarrollo, organización del código y preparación para despliegues reales.

Estos proyectos estarán orientados a demostrar capacidades en el desarrollo de sistemas completos, más allá de aplicaciones frontend o prototipos.
