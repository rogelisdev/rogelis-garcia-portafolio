    SVC_02 // INVENTORY SYSTEM

    Inventory Manager

    Problema La gestión manual de productos y existencias generaba errores, pérdida de control y falta de visibilidad en el inventario.
    Solución Aplicación web para registrar productos, controlar stock y gestionar ventas desde una interfaz centralizada.
    Arquitectura Aplicación frontend con almacenamiento local (LocalStorage), diseñada para ser ligera, rápida y adaptable.
    Resultado Mejor control del inventario, reducción de errores manuales y acceso rápido a la información de productos.
    JavaScript LocalStorage HTML&CSS
